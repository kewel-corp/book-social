# データセットについて

**このリポジトリにデータは含まれていません。** 本書で使用する公開データセットの入手先を、
以下にまとめます。取得は各配布元の利用条件に従ってください。

## 使う前に、必ず

**ライセンスと品質は、別問題です。** 商用利用可であることは、「そのまま学習に投入してよい」
ことを一切意味しません。公開データにも誤ったラベルは含まれており、しかも検証データにも同じ
誤りが混じっていれば、**評価指標は何も異常を告げません**（実装編の眼底写真の章）。

使う前に、次の三段を通してください。

1. **専門医による目視検分** ― 臨床的に納得できない症例は、削除ではなく「除外」として隔離し、理由を記録する
2. **クラス定義の突き合わせ** ― 配布元の定義が、自分の課題の定義と一致しているか
3. **誤ラベルの機械的な洗い出し** ― confident learning などで候補を挙げ、専門医が確認する

## 本書で扱うデータセット

各配布元のページで、**ライセンス（とくに商用可否）と確認日を台帳に記録**してください。
非商用（NC）や継承（SA）条件のデータで学習した重みは、商用の医療機器には原則として使えません。

| 分野 | データセット | 本書での用途 |
|------|--------------|--------------|
| 眼科 | 糖尿病網膜症の眼底写真（病変アノテーション付き） | 入門編・実装編の検出／セグメンテーション |
| 眼科 | OCT（黄斑疾患の分類） | 入門編の完全チュートリアル、実装編の層構造ガイド型AI |
| 整形外科 | 四肢・骨盤X線（骨折） | 入門編の分類、実装編の検出 |
| 消化器 | 腹部CT（肝臓・腫瘍のセグメンテーション） | 基礎編の3次元セグメンテーション、実装編の膵がんE2E |

具体的な配布元URLと取得手順は、各章のノートブック冒頭に記載しています。
**配布条件は変わることがあるため、URLをここに固定せず、ノートブック側で最新を案内する方針です。**

## 置き場所

手元で作業する場合、このディレクトリ配下にデータを置いてください。
`.gitignore` により `data/` 配下は追跡されません（この README を除く）。

```
data/
├── README.md      ← これ
├── eye/           （追跡されない）
├── bone/          （追跡されない）
└── abdomen/       （追跡されない）
```

**自施設のデータをここに置く場合も、匿名化を済ませてからにしてください。**
Gitの履歴は消えません（入門編 第7章）。
