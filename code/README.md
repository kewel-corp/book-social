# code/ ― 章をまたいで使う部品

各章のノートブックから使い回す、データ・損失関数・評価指標をまとめています。

| ファイル | 中身 |
|----------|------|
| `datasets.py` | 患者単位分割、`dataset.csv` の読み込み、画像とマスクの安全なリサイズ |
| `losses.py`   | Dice / Tversky / Focal / Dice+BCE |
| `metrics.py`  | 混同行列、感度・特異度・適合率、Dice / IoU、病変の等価楕円短軸長（臨床の短径の近似。名前に注意） |

**ここに置いた関数には、`tests/` に単体テストが付いています。**
壊れても例外を投げず、もっともらしい数字を返す種類のコードだからです
（社会実装編「臨床ロジックは、単体テストで守る」の節）。

```bash
pip install -r requirements.txt pytest
pytest tests/ -q
```

とくに次の三つは、書き換えたら必ずテストを回してください。

- **患者単位分割** ― 同じ患者が学習と評価にまたがると、成績は上がる。だから気づけない
- **病変の径** ― 係数を取り違えると値が半分や二倍になる。例外は出ない。返すのは等価楕円の短軸長で、輪郭上で測る臨床の短径とは別物
- **マスクのリサイズ** ― 線形補間をかけると、存在しないクラスIDが生まれる
