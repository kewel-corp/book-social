## 使い方

多くのノートブックは Google Colab でも動きますが、本書は手元の開発環境（WSL2＋Docker＋GPU。実装編の第I部）を前提にした章を含みます。

1. 上のノートブックを開き、Colab のバッジ（または「Open in Colab」）から起動する
2. ランタイムのタイプを **GPU** に変更する
3. セルを上から順に実行する

手元のマシンで動かす場合：

```bash
git clone https://github.com/kewel-corp/book-social.git
cd book-social
```

## 守っていただきたい一線

**患者データを、このリポジトリに置かないでください。**

Gitの履歴は消えません。一度コミットすると、削除して再コミットしても過去の版から取り出せます
（入門編 第7章）。`.gitignore` で DICOM・NIfTI・配列形式を機械的に締め出していますが、
最後に効くのは運用です。

Colab に載せてよいのは、**公開データセットと、自分で作った合成データだけ**です。
自施設のデータを扱う段取り（倫理審査 → 匿名化 → シリーズ選択 → ラベル定義 → 対応表）は、
入門編 第11章で扱っています。
